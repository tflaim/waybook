# Agent notes

These notes apply to any coding agent working in this repo.

To verify changes, read and follow `skills/verify-waybook/SKILL.md`.

Install the git hooks once per clone: `git config core.hooksPath githooks` (commit-msg blocks cursoragent@cursor.com; Co-authored-by, Generated-by, and Made-with trailers; Key: lines with cursor.com, claude.ai, or claude.com URLs; 'Docs: https://cursor.com/...'-style lines are rejected, so reword them; Markdown links to those; 'Generated with [Claude Code'; CURSOR_AGENT_PR_BODY; 🤖). The hooks also reject Coauthored and Co_authored spellings, Co-developed-by, Suggested-by, Tested-by, Assisted-by, Reviewed-by, and Signed-off-by lines that name an AI, a Generated by or with line naming Claude, Cursor, or ChatGPT, text hidden behind NBSP, zero-width characters, a full-width colon, CR or CRLF, a leading `>`, and folded continuation lines, and they scan tag messages. pre-push allows tflaim/* branches and tags, refuses main and master, and re-checks pushed commits (`sh githooks/test.sh`).

Every commit must be authored and committed by Thomas Flaim <tflaim@gmail.com> with no Co-authored-by trailers.
